# Pogee AI - Engineering Notes: Persistent Memory for AI Characters

Engineering notes on persistent memory and emotional continuity for AI characters. See https://pogee.ai

## Highlights

### Three-Tier Memory

Working, episodic, and semantic memory keep context small while preserving what matters.

### Emotional State

A slowly-decaying emotion vector lets characters be hurt, comforted, and reconciled.

### Retrieval at Inference

Relevant memories are fetched and injected before every reply.
